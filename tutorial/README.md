# HIT Hoopers: build-it-yourself guide

This folder explains how the HIT Hoopers website was made. Read the files in this order:

1. `01-project-setup.md`
2. `02-html-pages.md`
3. `03-css-design.md`
4. `04-javascript.md`
5. `05-php-form.md`
6. `06-testing-and-hosting.md`

## Finished project structure

```text
Html/
├── index.html             Home page
├── about.html             About, mission, vision and committee
├── events.html            Events generated by JavaScript
├── gallery.html           Photo gallery
├── contact.html           Join/contact form
├── process-form.php       PHP thank-you response
├── css/style.css          Shared design and animation
├── JS/script.js           Events, validation and scroll effects
├── images/                All gallery photos
└── tutorial/              These notes
```

## Assignment checklist

| Requirement | Where it appears |
| --- | --- |
| Five interconnected pages | `index`, `about`, `events`, `gallery`, `contact` |
| Headings, links, lists, table, form | All HTML pages; table on About; form on Join |
| External CSS and box model | `css/style.css` |
| Array, object, loop and function | `JS/script.js` |
| Events/interaction | form submit, scrolling, hovering and clicking links |
| PHP form processing | `process-form.php` |
| Images | `images/` and `gallery.html` |

## Important rule

Do not rename or move a file without updating every link that points to it. For example, if you rename `gallery.html`, the navigation links on all five pages need the new filename.
